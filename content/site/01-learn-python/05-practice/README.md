# Practice

Reading about a tool and reaching for it unprompted are different skills.
This section is 120 short problems that mix everything from Modules 1
to 4 with no labels: nothing tells you whether a problem wants a dictionary,
a slice or a stack. Working that out is the exercise.

This is the goal of the whole course: being able to solve all 120 on
your own, without asking anyone. Hints and reference solutions are here,
and using them is fine while you learn, but the finish line is a pass
through every problem without needing hints, solutions or an assistant.

You can start here at any time, but the problems assume you have been
through the four modules. If one stumps you, the first hint names the tool
and you can go back to its page.

The problems are grouped by difficulty, not by topic:

| Band | Pages | Feels like |
|------|-------|------------|
| Warm-up | 3 | One idea, a line or a short loop |
| Standard | 4 | Two ideas combined |
| Stretch | 2 | Several ideas, or a small program |
| Hard | 3 | Classic methods described in words for you to implement: searching and sorting, structures working together, lists and positions |

Skip anything that sticks and come back later. There is no gate.

Some problems say "the point is to practise X rather than use Y". The
checks only test that your answer is correct, so a solution using Y still
passes; the sentence tells you which method the problem is there to teach.

## If you have an AI assistant

Use it as a tutor, not as an answer machine. Every exercise has a **Copy
tutor prompt** button under the editor. It copies your code, your last
results, and a set of instructions that make the assistant ask you
questions and send you back to the lessons instead of handing you the
solution. Paste it into whatever assistant you use, then answer its
questions honestly. If it gives you code anyway, close it and come back.
The goal is still a pass through all 120 without needing it.
