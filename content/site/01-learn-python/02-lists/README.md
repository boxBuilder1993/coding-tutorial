# Lists

A list holds many values in order. You make one with square brackets.

```python
fruits = ["apple", "pear", "fig"]
print(len(fruits))
print(fruits[0])
print(fruits[-1])
```

Positions start at 0, so `fruits[0]` is the first item. Negative positions
count from the end.

## Going through a list

A `for` loop runs its indented lines once for each item.

```python
scores = [70, 85, 92]
for s in scores:
    print(s)
```
