# Learn Python

A track for people who have never programmed. Each page introduces one idea,
lets you run small examples, and ends with short exercises you solve right on
the page. Nothing to install.

Work through the pages in order. Each takes about half an hour.

The examples use a small shop throughout: items like `apple` and `bread`,
prices, quantities, and a shopping list. The vocabulary stays the same so you
can focus on the Python, not the story.
