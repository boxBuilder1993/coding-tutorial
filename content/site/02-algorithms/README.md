# Algorithms

Everything in [Learn Python](../01-learn-python) was about getting the right
answer. The practice problems accepted any solution that worked, however
slowly. This section is about the next question: **how much work does the
code do**, and what to do when the answer is "too much".

The pages here are shorter than the earlier ones and expect you to be
comfortable with lists, dictionaries, loops and functions. If you are not,
go back and do the practice problems first; nothing here will make sense
without them.

1. [Counting steps](01-counting-steps): measure what code costs and name the common growth shapes.
2. [Recursion](02-recursion): functions that call themselves, and the problems that need them.

More pages follow as they are written.
