# Double the price

Write `double_price(price)` that returns twice the price.

```static
double_price(40)   ->  80
double_price(2.5)  ->  5.0
```

## Starter

```python
def double_price(price):
    ...
```

## Hints

1. Arithmetic and `return`.
2. `return price * 2`

## Approach

Multiply and return.

## Reference

```python
def double_price(price):
    return price * 2
```
