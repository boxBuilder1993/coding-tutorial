# Even number?

Write `is_even(n)` that returns `True` if `n` is even.

```static
is_even(4)  ->  True
is_even(7)  ->  False
```

## Starter

```python
def is_even(n):
    ...
```

## Hints

1. The remainder when dividing by 2.
2. `n % 2 == 0`

## Approach

Even numbers leave no remainder when divided by 2.

## Reference

```python
def is_even(n):
    return n % 2 == 0
```
