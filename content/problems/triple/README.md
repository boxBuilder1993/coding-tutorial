# Triple

Write a function `triple(x)` that returns three times `x`.

```static
triple(5)   ->  15
triple(2.5) ->  7.5
```

## Starter

```python
def triple(x):
    ...
```

## Hints

1. The body needs a `return` line.
2. `return x * 3`

## Approach

A one-line body: `return x * 3`. If the checks say they got `None`, you printed instead of returning.

## Reference

```python
def triple(x):
    return x * 3
```
