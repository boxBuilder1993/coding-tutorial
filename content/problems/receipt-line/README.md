# Receipt line

Three apples at 40 each. Print the total on one line, exactly like this:

```static
Total: 120
```

Let Python do the multiplication. Do not type `120` yourself.

## Starter

```python
print("Total:", ...)
```

## Hints

1. `print` can take several values separated by commas, and puts a space between them.
2. Replace the `...` with `40 * 3`.

## Approach

`print("Total:", 40 * 3)`. The string and the number are separate values; `print` joins them with a space.

## Reference

```python
print("Total:", 40 * 3)
```
