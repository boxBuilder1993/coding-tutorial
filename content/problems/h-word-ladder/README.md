# Word ladder

Write `ladder_length(start, end, words)` that returns the length (number of words,
including both ends) of the shortest sequence from `start` to `end` where each step
changes exactly one letter and every intermediate word is in `words`. `end` must be in
`words`. Return `0` if no such sequence exists.

```static
ladder_length("hit", "cog", ["hot", "dot", "dog", "lot", "log", "cog"])  ->  5     (hit, hot, dot, dog, cog)
ladder_length("hit", "cog", ["hot", "dot", "dog", "lot", "log"])         ->  0
```

BFS where the neighbours of a word are generated by trying every letter in every
position and keeping those in the word set.

## Starter

```python
def ladder_length(start, end, words):
    ...
```

## Hints

1. `word_set = set(words)`; if `end` is not in it, return 0. Queue of `(word, steps)` starting at `(start, 1)`.
2. Neighbours: for each position and each letter `a`-`z`, build the candidate; if it is in the set, remove it from the set (visited) and queue it.
3. Return steps when `end` is popped.

## Approach

Breadth-first search over words; removing a word from the set when first reached is the visited mark. Cost is words times length times 26.

## Reference

```python
from collections import deque
import string

def ladder_length(start, end, words):
    pool = set(words)
    if end not in pool:
        return 0
    queue = deque([(start, 1)])
    pool.discard(start)
    while queue:
        word, steps = queue.popleft()
        if word == end:
            return steps
        for i in range(len(word)):
            for ch in string.ascii_lowercase:
                cand = word[:i] + ch + word[i + 1:]
                if cand in pool:
                    pool.remove(cand)
                    queue.append((cand, steps + 1))
    return 0
```
