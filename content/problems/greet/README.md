# Greet

Write a function `greet(name)` that returns the text `Hello, <name>!`.

```static
greet("Ada")  ->  "Hello, Ada!"
```

## Starter

```python
def greet(name):
    ...
```

## Hints

1. Join pieces of text with `+`.
2. Don't forget the comma and the space after it, and the exclamation mark at the end.

## Approach

Build the string from three parts: `"Hello, "`, the name, and `"!"`.

## Reference

```python
def greet(name):
    return "Hello, " + name + "!"
```
