# Name and print

Create a name `item` that refers to the text `bread`, then print the line
`You bought bread` using the name, not by typing the word again.

```static
You bought bread
```

## Starter

```python
item = ...
print("You bought", ...)
```

## Hints

1. Text goes in quotes: `item = "bread"`.
2. Pass the name to `print`, not the word in quotes: `print("You bought", item)`.

## Approach

Assign the string to `item`, then print the label and the name as two values.

## Reference

```python
item = "bread"
print("You bought", item)
```
